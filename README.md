# DAMAS RADIO

Cyberpunk Radio Streaming Player

## Features

- 17 Online Radio Stations
- Dynamic Theme Colors
- Glitch Text Animation
- 3D Tilt Card Effects
- Mouse Parallax
- Custom Cursor with Sparks
- Audio Visualizer
- Lightning & Star Particles
- Noise Grain Overlay
- Favorites System (localStorage)
- Hamburger Menu
- Developer Info Modal
- Effects Toggle (Performance Mode)
- PWA (Installable)
- Offline Caching

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API
- Canvas
- Service Worker (PWA)

## Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/DAMAS-RADIO.git
```

2. Open `index.html` in your browser

## PWA

This app is a Progressive Web App. You can install it on your phone or desktop by clicking "Install" in the browser address bar.
